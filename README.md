# Расписание ГУЗ — Telegram Mini App

Статичное приложение в стиле iOS. Хостинг — GitHub Pages (бесплатно), автообновление — GitHub Actions каждые 3 часа.

## Как это работает
1. GitHub Actions каждые 3 часа (и при каждом пуше в `main`) запускает `scripts/fetch.mjs`.
2. Скрипт берёт из API РУЗ (`/api/search`, `/api/schedule/group/{id}`) **список всех групп вуза** и расписание каждой, складывает в `data/`.
3. `data/` публикуется вместе с сайтом на GitHub Pages и в git не хранится — репозиторий не разрастается.
4. Мини-апп читает `data/*.json` со своего же домена: поиск группы с подсказками работает мгновенно и без прокси, любая группа открывается сразу.

Если сайт вуза по какой-то группе не ответил, остаётся её прошлая копия. Если не ответил совсем — сайт не передеплоивается и работает со старыми данными.

## Запуск за 5 минут
1. Создай публичный репозиторий на GitHub и залей туда все файлы из архива (включая папку `.github`).
2. В `config.json` впиши свои группы — они выгружаются первыми, даже если общий список не загрузился:
   ```json
   "groups": ["ЗК-24-1", "ЗК-24-2"]
   ```
3. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
4. **Actions → «Обновление расписания и деплой» → Run workflow.** Через минуту сайт будет на `https://<логин>.github.io/<репо>/`. Дальше он обновляется сам: при каждом пуше в `main` и каждые 3 часа.
5. В [@BotFather](https://t.me/BotFather): `/newbot` → создать бота, затем `/mybots` → бот → **Bot Settings → Menu Button** → вставить ссылку на сайт. Кнопка «Расписание» появится в чате с ботом. Сервер для бота не нужен.
   - По желанию `/newapp` — получишь прямую ссылку вида `t.me/bot/app`. Можно открыть сразу нужную группу: `t.me/bot/app?startapp=<id группы>`.

## Поиск группы
Нажми на название группы сверху и начни вводить, например `З.КН` или `24.Б7`, — подсказки появятся сразу из общего списка. Регистр, пробелы и точки не важны, «3» вместо «З» и латинские буквы-двойники тоже понимаются. Выбранная группа и последние выбранные запоминаются.

Ссылка сразу на группу: `https://<логин>.github.io/<репо>/?group=З.КН.24.Б7`.

Чтобы выгружать только группы из `config.json`, поставь там `"allGroups": false`.

### Прокси (необязательно)
Нужен, только чтобы видеть изменения в расписании раньше, чем через 3 часа, и находить группы, появившиеся после последней выгрузки. Браузер пускает мини-апп на сайт вуза, только если тот разрешает это заголовком CORS; ruz.guz.ru не разрешает, поэтому нужен свой прокси. Это бесплатно и без сервера:
1. Зарегистрируйся на [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Worker**.
2. Вставь код из `proxy/worker.js` → **Deploy**. Получишь адрес вида `https://ruz-proxy.<имя>.workers.dev`.
3. В `index.html` найди `proxy: ''` и впиши туда этот адрес.

Бесплатный лимит — 100 000 запросов в день, для группы студентов с запасом.


## Если в Actions ошибка подключения
Многие сайты вузов не пускают зарубежные IP, а серверы GitHub — за границей. Тогда сайт задеплоится с прошлыми данными, а обновлять можно так:
- подключить свой компьютер как self-hosted runner (Settings → Actions → Runners) и поменять `runs-on: ubuntu-latest` на `runs-on: self-hosted` в job `build`.

## Если API у сайта отличается
Открой ruz.guz.ru, DevTools (F12) → Network → выбери группу и посмотри, какой запрос возвращает пары. Поля маппятся в функции `lesson()` в `scripts/fetch.mjs` — поправить там.

## Мелочи
- GitHub отключает cron в репозитории без активности 60 дней (например, летом) — включается кнопкой в Actions.
- Выбранная группа запоминается (localStorage + Telegram CloudStorage).
- Без интернета показывается последнее загруженное расписание.
- Без данных (локальный запуск без `node scripts/fetch.mjs`) открывается демо-группа.
